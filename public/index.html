Inicie o AOF Studio

Para abrir no Windows, use o AOF Studio.exe ou o iniciador iniciar-windows.vbs. Abrir o arquivo index.html diretamente não inicia o sistema.

O aplicativo abre em uma janela própria, sem CMD. Ao fechar essa janela, o sistema é encerrado.

Executar pelo código-fonte

Use o Node.js 24 LTS (instalado ou portátil). Depois, abra um terminal na pasta do projeto, onde está o arquivo package.json, e execute: 

npm ci
npm start

Mantenha o terminal aberto e acesse http://localhost:3000 no navegador.

No Windows sem administrador, consulte a seção Sem administrador no Windows do README. Use o ZIP portátil do Node.js e o arquivo iniciar-windows.vbs na pasta do projeto.

Se você publicou em uma hospedagem, ela precisa executar o servidor Node.js e manter o banco de dados. GitHub Pages e outros serviços somente de arquivos estáticos não executam este sistema.
