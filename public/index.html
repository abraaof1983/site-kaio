Inicie o AOF Studio

Este sistema precisa do servidor Node.js para salvar cadastros e gerar PDFs. Abrir o arquivo index.html diretamente não inicia o sistema.

Instale o Node.js 24 LTS. Depois, abra um terminal na pasta do projeto, onde está o arquivo package.json, e execute: 

npm ci
npm start

Mantenha o terminal aberto e acesse http://localhost:3000 no navegador.

Se você publicou em uma hospedagem, ela precisa executar o servidor Node.js e manter o banco de dados. GitHub Pages e outros serviços somente de arquivos estáticos não executam este sistema.
